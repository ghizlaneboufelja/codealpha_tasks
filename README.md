# CodeAlpha Cyber Security Internship — Tasks

**Author:** Ghizlane Boufelja

This repository contains my completed projects for the CodeAlpha Cyber Security Internship.

## Task 1 — Basic Network Sniffer
A Python and Scapy project that captures IPv4 packets and displays source and destination IP addresses, protocols, packet sizes, and available payload information.

Project folder: `Task1_BasicNetworkSniffer/`

## Task 2 — Phishing Awareness Training
A cybersecurity awareness project that explains phishing warning signs, suspicious websites, social-engineering techniques, prevention practices, and includes a knowledge-check quiz.

Project folder: `Task2_PhishingAwarenessTraining/`

## Responsible Use
The network sniffer should only be used on devices and networks for which permission has been granted. The phishing-awareness material is intended for education and prevention.

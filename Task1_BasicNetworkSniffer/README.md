# CodeAlpha Basic Network Sniffer

## 1. Project Overview

This project is a basic network sniffer developed in Python as part of the CodeAlpha Cyber Security Internship.

It captures IPv4 packets and displays useful information about network traffic.

## 2. Features

- Capture IPv4 packets using Scapy.
- Display source and destination IP addresses.
- Identify TCP, UDP, ICMP, and other IP protocols.
- Display TCP and UDP source and destination ports.
- Display packet size.
- Show a short hexadecimal preview of available raw payload data.
- Count captured packets and summarize protocol distribution.

## 3. Technologies Used

- Python 3
- Scapy
- Kali Linux

## 4. Requirements

- Python 3
- Scapy
- Appropriate permissions for packet capture

## 5. Installation

Install Scapy on Kali Linux:

```bash
sudo apt update
sudo apt install -y python3-scapy
```

Clone or download this repository, then navigate to the project directory.

## 6. Execution

Run the program:

```bash
sudo python3 network_sniffer.py
```

Press `Ctrl+C` to stop the capture and display the summary.

## 7. Testing

The program was tested on Kali Linux using network traffic generated by commands such as `ping`, DNS lookups, and HTTPS requests.

One test session analyzed 773 IPv4 packets:

- TCP: 477 packets
- UDP: 288 packets
- ICMP: 8 packets

These results describe one test session and may differ in other environments.

## 8. Security and Ethical Use

Use this tool only on your own device or on networks for which you have explicit authorization.

The program does not decrypt HTTPS communications. Payload previews may contain sensitive data, so capture logs should be handled carefully.
